# Блок-схема системы Shadow-QC

## Общий пайплайн

```mermaid
graph TB
    A[Папка с фото] --> B[Поиск файлов JPG/PNG/TIF]
    B --> C[Параллельная обработка]
    C --> D[Resize 1280px + Blur]
    D --> E[Конвертация в LAB]
    E --> F[Теневая маска]
    E --> G[Извлечение признаков]
    F --> G
    G --> H[shadow_score]
    H --> I[Классификация]
    I --> J{Результат}
    J -->|good| K[Rating=5, Green]
    J -->|review| L[Rating=3, Yellow]
    J -->|bad| M[Rating=1, Red]
    K --> N[CSV-отчёт]
    L --> N
    M --> N
    N --> O{dry-run?}
    O -->|да| P[Только CSV]
    O -->|нет| Q[ExifTool batch запись]
    Q --> R[Метаданные в файлах]
```

## Модуль теневой маски

```mermaid
graph TB
    A[LAB изображение] --> B[L-канал нормализованный]
    B --> C[Локальный фон: blur L]
    B --> D[Локальное отклонение: local_std]
    C --> E[Порог: L < mean - k*std]
    D --> E
    E --> F[Грубая маска]
    A --> G[CIELCh: Specthem ratio]
    G --> H[Цветовая маска]
    F --> I[Объединение масок]
    H --> I
    I --> J[Морфология: open/close]
    J --> K[Фильтр по площади]
    K --> L[Финальная теневая маска]
```

## Классификация

```mermaid
graph TB
    A[Вектор признаков] --> B{Режим?}
    B -->|rules| C[Пороговые правила]
    B -->|ml| D[LogisticRegression]
    C --> E[shadow_score < 0.25 AND lc < 0.22?]
    E -->|да| F[GOOD]
    E -->|нет| G[shadow_score > 0.55 OR lc > 0.38?]
    G -->|да| H[BAD]
    G -->|нет| I[REVIEW]
    D --> J[P good/bad]
    J --> K[P bad > 0.7 → BAD]
    J --> L[P good > 0.7 → GOOD]
    J --> M[else → REVIEW]
```

## Запись метаданных

```mermaid
graph TB
    A[CSV решений] --> B[Группировка по классам]
    B --> C[ExifTool batch -stay_open]
    C --> D[XMP-xmp:Rating]
    C --> E[XMP-acdsee:Rating]
    C --> F[XMP-xmp:Label]
    C --> G[XMP-dc:Subject += keyword]
    C --> H[IPTC:Keywords += keyword]
    D --> I[Файл обновлён]
    E --> I
    F --> I
    G --> I
    H --> I
    I --> J[ACDSee: перекаталогизировать]
```

## Структура проекта

```
shadow-qc/
├── config.yaml           ← пороги, пути, параметры
├── requirements.txt
├── src/
│   ├── __init__.py
│   ├── cli.py            ← argparse, точка входа
│   ├── pipeline.py       ← оркестрация всего
│   ├── features.py       ← вектор признаков
│   ├── shadow_mask.py    ← теневая маска
│   ├── classify.py       ← правила / ML
│   ├── metadata.py       ← ExifTool batch
│   └── utils.py          ← IO, resize, helpers
├── scripts/
│   ├── calibrate.py      ← калибровка на размеченном наборе
│   └── visualize_debug.py← overlay масок
├── data/
│   ├── input/            ← фото для обработки
│   ├── labeled.csv       ← ручная разметка
│   └── predictions.csv   ← результат
└── debug/
    ├── masks/
    └── overlays/
```

## Критерии приёмки

- [ ] CLI обрабатывает папку, выдаёт CSV с метриками и классами
- [ ] `--dry-run` не модифицирует файлы
- [ ] Без `--dry-run` пишет Rating/Label/Keywords в JPEG
- [ ] ACDSee видит и фильтрует по Rating и Keywords
- [ ] Debug-визуализация показывает теневую маску поверх фото
- [ ] Скорость: ≥5 кадров/сек на CPU (resize 1280)
- [ ] Пороги настраиваются через config.yaml без правки кода
